### [World Cup 2026 Match Predictor](https://github.com/sovithyea/wc26_ro32_predictor)
> *Because someone has to do the maths before the tournament.*

ML system predicting match outcomes and scorelines for the FIFA World Cup 2026, blending two models: a calibrated XGBoost win/draw/loss classifier and a Dixon-Coles Poisson model for scorelines.

- **How it works:** `main.py::_blend_proba` combines a `CalibratedClassifierCV` (isotonic) wrapped XGBoost classifier (15 features — ELO diff, group-stage form, H2H record, rest days, knockout goals) with a Dixon-Coles Poisson model fitted via MLE for attack/defence strength, at a 60/40 blend
- **Data:** 49k+ historical international results (`martj42/international_results`) plus hand-curated WC26 group stage/R32/R16 results
- **Honesty check:** no held-out test set or backtest yet — these are the model's stated probabilities, not validated accuracy. Backtest (leave-one-WC-out on 2006–2022 knockouts) is next
- **Tech:** `Python` `pandas` `scikit-learn` `XGBoost` `SciPy` `Streamlit` `Plotly`

### [2026 F1 Race Predictor](https://github.com/sovithyea/2026_f1_prediction) (In Progress)
> *Predicting who DNFs so you don't have to.*

Live-updating ML system predicting race finishing positions for every round of the 2026 F1 season, trained on real FastF1 telemetry as the season unfolds.

- **How it works:** A Gradient Boosting Regressor trains incrementally on completed 2026 rounds, using qualifying gaps, FP1/FP2/FP3 deltas, and team performance scores. FP2 long-run pace weighted most heavily, with fallback for sprint weekends
- **Currently tracking:** 7 rounds complete, season accuracy logged via `tracker.py`
- **Tech:** `Python` `scikit-learn` `FastF1` `Pandas` `Matplotlib`
